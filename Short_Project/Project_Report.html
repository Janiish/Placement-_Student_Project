1 Abstract

The Grand Luxury Hotel Management System is a single-file, self-contained Java desktop application that provides a comprehensive solution for hotel room booking, guest check-in/check-out management, billing and invoicing, and real-time dashboard analytics. Built using Java Swing with a premium custom-painted GUI, the application demonstrates object-oriented programming principles, event-driven architecture, and modern UI design patterns.

The project also includes an HTML/CSS web portal component that can be auto-generated from within the application, serving as a presentation layer for academic submissions. The system supports both in-memory data persistence and an optional MongoDB connection hook, making it adaptable for both demonstration and production-like environments.

📌
Key Highlight: The entire application — GUI, business logic, data layer, and HTML export — is contained in a single Java file (828 lines), requiring zero external dependencies beyond the standard JDK.

2 Introduction

2.1 Background

The hospitality industry relies heavily on efficient management systems to handle guest bookings, room allocation, billing, and record-keeping. Traditional manual methods are error-prone, time-consuming, and difficult to scale. A computerized hotel management system eliminates these challenges by automating routine tasks, improving accuracy, and providing real-time visibility into hotel operations.

2.2 Purpose of the Project

This project aims to develop a desktop-based Hotel Management System using core Java technologies. It serves as both a functional prototype of a real-world hotel management solution and an academic project demonstrating:

🎨 Java Swing GUI

Custom-painted components with gradients, rounded buttons, card layouts, and hover animations

🧩 Object-Oriented Design

Encapsulation, inner classes, data modeling, and separation of concerns

⚡ Event-Driven Programming

ActionListeners, MouseListeners, and dynamic user interaction handling

🌐 HTML/CSS Integration

Automatic responsive web page generation from within the Java application

3 Problem Statement & Objectives

3.1 Problem Statement

Hotels require an integrated system that handles room reservations, guest tracking, billing with tax computation, and operational analytics in a single, easy-to-use interface. Manual record-keeping leads to overbookings, billing errors, and lost revenue. There is a need for a lightweight, portable solution that does not require complex server infrastructure but can optionally connect to databases for persistent storage.

3.2 Objectives

  • Design and develop a user-friendly Java Swing GUI application for hotel management with a premium, modern look and feel.
  • Implement core hotel operations: room booking, check-in, check-out, and invoice generation with GST tax computation.
  • Create an interactive dashboard displaying real-time statistics (total bookings, current occupancy, total revenue).
  • Build custom UI components (gradient panels, rounded buttons, card panels, styled text fields) for a professional appearance.
  • Integrate automatic HTML/CSS web page generation for project presentation and academic submission.
  • Provide dual-mode data storage — in-memory ArrayList for immediate use and MongoDB driver detection for database connectivity.
  • Demonstrate clean OOP design with inner classes, encapsulated data models, and separation of concerns.

6 Module Description

The application is organized into four main functional modules, each represented as a tab in the user interface:

6.1 Module 1 — Room Booking

Purpose: Allows the front desk operator to create new guest reservations.

📝 Guest Form

Full Name, Phone Number, Room Category dropdown, Stay Duration input

💰 Price Calculation

Real-time total estimate based on room type × number of days

🔢 Auto-Generation

Unique Booking ID (from 1001), Room Number, Date stamp

✅ Input Validation

Empty check, numeric validation, positive integer enforcement

Room CategoryRate / Night (₹)Amenities Included
Standard₹1,500Wi-Fi, TV, AC, Work Desk
Deluxe₹2,800Balcony View, King Bed, Complimentary Breakfast
Executive Suite₹5,000Jacuzzi, Living Area, 24/7 Personal Butler

6.2 Module 2 — Check-In / Check-Out & Billing

Purpose: Manages guest status transitions and generates detailed invoices.

  • Booking search by ID with instant invoice preview
  • Status update to Checked-In or Checked-Out
  • Detailed ASCII-art invoice with room charges, GST (12%), Service Charge (5%), and Grand Total
  • Invoice rendered in monospaced font (Consolas) for precise alignment

Billing Formula

Subtotal      = Room Rate × Number of Days
GST (12%)    = Subtotal × 0.12
Service (5%) = Subtotal × 0.05
Grand Total  = Subtotal + GST + Service Charge

6.3 Module 3 — All Booking Records

Purpose: Displays a comprehensive table of all bookings with 9 columns.

  • Columns: ID, Guest Name, Phone, Room Type, Room #, Days, Total (₹), Date, Status
  • Custom DefaultTableCellRenderer for alternating row colors
  • Color-coded status: Booked   Checked-In   Checked-Out
  • Non-editable cells, styled header with primary color background

6.4 Module 4 — Dashboard

Purpose: Provides at-a-glance operational analytics and system configuration.

  • Total Bookings — Count of all reservations
  • Currently Checked-In — Active guests count
  • Total Revenue — Sum of all booking values (₹)
  • System info: Java version, OS name, MongoDB connection status
  • HTML export button to generate and launch hotel.html

9.3 MongoDB Integration Hook

private void checkMongoConnection() {
    try {
        Class.forName("com.mongodb.client.MongoClients");
        mongoAvailable = true;    // Display: CONNECTED
    } catch (ClassNotFoundException e) {
        mongoAvailable = false;   // Display: IN-MEMORY MODE
    }
}

The system uses reflection-based driver detection (Class.forName) to check if the MongoDB Java driver is available on the classpath without creating a hard compile-time dependency.

12 Advantages & Limitations

12.1 Advantages

  • Zero Dependencies — Runs with just the standard JDK; no external libraries, build tools, or servers required.
  • Single-File Architecture — The entire application (828 lines) is in one .java file, easy to distribute and submit.
  • Premium UI Design — Custom-painted components with gradients, rounded corners, shadows, and hover animations.
  • Dual Storage Mode — Seamlessly falls back to in-memory when MongoDB is unavailable.
  • Cross-Platform — Runs on Windows, macOS, and Linux with any JRE 8+ installation.
  • Auto HTML Export — Generates a responsive web portal from within the application.
  • Real-Time Dashboard — Provides instant analytics without manual report generation.
  • Professional Invoices — Formatted ASCII-art invoices with GST + service charge calculations.

14 Conclusion

The Grand Luxury Hotel Management System successfully demonstrates the development of a fully functional, visually polished desktop application using core Java technologies. The project achieves all stated objectives:

  • A premium Swing GUI with custom-painted components, gradient effects, and card-based layouts
  • Complete room booking workflow with input validation and automatic ID generation
  • Check-in/check-out management with detailed GST-inclusive invoice generation
  • An interactive records table with color-coded statuses and alternating row styling
  • A real-time analytics dashboard with key metrics (bookings, occupancy, revenue)
  • Automatic HTML/CSS web portal generation for academic presentation
  • Dual-mode storage with graceful fallback from MongoDB to in-memory mode

The single-file architecture (828 lines of Java) makes the project exceptionally portable and easy to evaluate, while the quality of the custom UI components demonstrates proficiency in Java 2D graphics, event-driven programming, and modern design principles. The project serves as a strong foundation that can be extended with database persistence, authentication, and REST APIs to become a production-ready hotel management solution.
